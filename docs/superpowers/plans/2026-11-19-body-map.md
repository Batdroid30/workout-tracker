# Body Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Front/back anatomical body map — heat-shaded per session on workout history cards, volume-status coloured for the current week on the Progress page (replacing the radar).

**Architecture:** Pure logic in `src/lib/body-map/` (muscle→region mapping, session intensity). A dumb `BodyMap` SVG component in `src/components/ui/BodyMap/` takes a fill per region and draws vendored MIT path data. Two thin callers decide colours: `SessionBodyMap` (heat) and `WeeklyBodyMapCard` (Phase Coach statuses).

**Tech Stack:** Next 16 / React 19, TypeScript, Tailwind, Vitest. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-19-body-map-design.md`

## Global Constraints

- No new npm dependency. Path data is copied from `react-body-highlighter` v2.0.5 (MIT, github.com/GV79/react-body-highlighter) with the MIT licence text + copyright in a header comment.
- `lib/` stays React-free (AGENTS.md §3).
- No `any`, no `as` casts in new code (AGENTS.md §2.3).
- One component per file; colocated folders with `index.ts` barrels.
- One counting rule everywhere per-muscle sets are shown (user decision 2026-11-19): primary = 1, each secondary = 0.5 per working set; warm-ups excluded. Implemented once in `src/lib/muscle-sets.ts` (Task 1b) and used by the weekly snapshot (→ Phase Coach + weekly map), the coach context, and the session map. Push/pull/legs and antagonist totals stay primary-only.
- Set counts can now be fractional — display them with at most one decimal (`7.5 sets`).
- Untrained muscles = neutral body fill, never a status colour.
- Must work at 375px width, light and dark.
- Commits: conventional format, imperative, ≤72 chars, no co-author trailers.

- Card payload: figure path data is emitted once per page (SVG `<symbol>`), cards reference it with `<use>` — profile history renders up to 200 cards (see Task 3).

## Review Focus

1. **Exercise with null/empty `secondary_muscles`, or unknown `muscle_group` string** (DB column is `string`) — must be skipped silently, not crash. Test in Task 2.
2. **Workout with zero working sets** (all warm-ups, or empty) — card shows a fully neutral body, no divide-by-zero NaN fills. Test in Task 2.
3. **`lats` and `back` both trained** — shared `upper-back` region takes the stronger value, not whichever was written last. Tests in Task 1.
4. **Week with no training yet (Monday morning)** — weekly card renders a neutral body with a short caption, not an all-red "Below MV" body. Test in Task 5.
5. **Supabase join returning `exercise` as an array or null** — intensity input must be normalised before use; a missing exercise is skipped. Covered in Task 4 mapping + Task 2 null test.

### Task 2: Session intensity

**Files:**
- Create: `src/lib/body-map/session-intensity.ts`
- Modify: `src/lib/body-map/index.ts` (export)
- Test: `src/lib/body-map/session-intensity.test.ts`

**Interfaces:**
- Consumes: `isMuscleGroup` (Task 1), `addSetToMuscleCounts` (Task 1b — use it for the raw scores, don't re-implement the rule)
- Produces:
  - `interface SessionExerciseInput { muscleGroup: string | null; secondaryMuscles: string[] | null; workingSetCount: number }`
  - `function calculateSessionIntensity(exercises: SessionExerciseInput[]): Partial<Record<MuscleGroup, number>>` — score per muscle (primary +1/set, each secondary +0.5/set), divided by the session's max score → values in (0, 1]. Muscles with 0 omitted. Unknown strings skipped.
  - `const HEAT_LEVELS = [0.25, 0.5, 0.75, 1] as const`
  - `function toHeatLevel(intensity: number): number` — smallest `HEAT_LEVELS` entry ≥ intensity.

- [ ] **Step 1: Write failing tests**

```ts
it('weights primary 1 and secondary 0.5 per set, normalised to max', () => {
  const r = calculateSessionIntensity([{ muscleGroup: 'chest', secondaryMuscles: ['triceps'], workingSetCount: 4 }])
  expect(r).toEqual({ chest: 1, triceps: 0.5 })
})
it('sums across exercises', () => {
  const r = calculateSessionIntensity([
    { muscleGroup: 'chest', secondaryMuscles: ['triceps'], workingSetCount: 4 },
    { muscleGroup: 'triceps', secondaryMuscles: null, workingSetCount: 2 },
  ])
  expect(r).toEqual({ chest: 1, triceps: 1 })   // triceps 2 + 2 = 4
})
it('returns {} when there are no working sets', () => {
  expect(calculateSessionIntensity([{ muscleGroup: 'chest', secondaryMuscles: [], workingSetCount: 0 }])).toEqual({})
  expect(calculateSessionIntensity([])).toEqual({})
})
it('skips null and unknown muscle strings', () => {
  const r = calculateSessionIntensity([
    { muscleGroup: null, secondaryMuscles: ['neck'], workingSetCount: 3 },
    { muscleGroup: 'quads', secondaryMuscles: null, workingSetCount: 3 },
  ])
  expect(r).toEqual({ quads: 1 })
})
it('toHeatLevel buckets up', () => {
  expect(toHeatLevel(0.1)).toBe(0.25)
  expect(toHeatLevel(0.5)).toBe(0.5)
  expect(toHeatLevel(0.51)).toBe(0.75)
  expect(toHeatLevel(1)).toBe(1)
})
```
